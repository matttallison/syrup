# PICO

An SP-1200-style sampling drum machine firmware for the M-VAVE FM-1, by Matt Allison. Rebuilt here from
zvenson/zp12 (main a7cc3dc, GPL-3.0; on SLOOP / Felucca) after the first PICO's source was lost: its design is in
SPEC.md and is being brought back in stages. Built by `.github/workflows/pico.yml`; each build goes to the
`pico-latest` release (`pico-0.6-beta.fwsc`, and `pico-build.log`).
